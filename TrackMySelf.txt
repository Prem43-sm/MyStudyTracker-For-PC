# TrackMySelf — OFFLINE WEBUI + XLSX ENGINE
## MASTER CODEX BUILD PROMPT

You are a senior full-stack engineer. Build a complete, production-quality **100% offline local WebUI engine** called:

**MyStudyTracker**

The application must provide a modern browser-based interface for entering, editing, viewing, and managing personal study/habit/work tracking data while using an **Excel `.xlsx` file as the primary human-readable data/workbook**.

The user should NOT need to manually open Excel for normal tracking.

The user opens the local WebUI, enters data there, and the engine automatically updates the Excel workbook.

---

# 1. CORE IDEA

The system replaces the handwritten monthly tracker shown in the reference workbook.

The user has customizable tracking items such as:

- Complete To-Do List
